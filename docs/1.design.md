# 1. Design — Scam Dojo

Audience: everyday people in India/JAPAC, mostly on mid-range Android phones, many not tech-confident, some over 50. Primary job: **make someone calmer and sharper about scams in under 3 minutes.**
Tone: a good sensei — steady, specific, never shaming, never alarmist.

---

## 1. Design intent and the one memorable thing

The product borrows its vocabulary from a martial-arts dojo, because the core behaviour we teach is **practice**. Scam tactics are *strikes*; the user's replies are *blocks*; progress is a *belt*.

**Boldness is spent in two places only:**
1. **The hero interaction on the home page**: a live, tappable fake bank SMS. The visitor chooses what to do (tap link / ignore / check it) and gets an honest, gentle consequence. This *is* the product in 10 seconds.
2. **The debrief replay + belt**: the finished conversation replays with each scammer *strike* marked **landed** or **blocked**, then the belt tightens into its new colour. This is the emotional payoff and the demo's closing shot.

Everything else is quiet, disciplined and fast.

### Review against generic defaults (what was rejected and why)
| First instinct | Why rejected | Chosen instead |
|---|---|---|
| Near-black + vermilion "dojo" look | Common generated-design cluster | **Indigo-dyed (aizome) ink + sage rice-paper**, belt colours used *functionally*; red only for danger signals |
| Cream background + serif display + clay accent | Same cluster | Cool sage paper, one sans family with width axis |
| Inter / Space Grotesk / mono labels | Template defaults | **Anek** family (Latin + Devanagari + Tamil share one design) |
| Identical rounded cards + grey shadows + gradient washes | SaaS-card kit | **Varied radii by role**, indigo-tinted layered shadow, no gradients as decoration |
| ALL-CAPS eyebrow above every heading, `A · B · C` metas | Template chrome | Sentence case, no eyebrows; structure only where it encodes information |

## 3. Typography

One family, using its variable axes: **Anek** (Google Fonts) — `Anek Latin` (wght 100–800, wdth 75–125), `Anek Devanagari`, `Anek Tamil`. Matching design across scripts means Hindi never looks like a fallback.

Load with `next/font/google`, `display: swap`, subset per script, variable axes. Fallback stack: `system-ui, "Noto Sans Devanagari", sans-serif`.

| Role | Size / line-height | Weight · width | Notes |
|---|---|---|---|
| Display (hero) | `clamp(40px, 9vw, 72px)` / 1.02 | 800 · wdth 118 | Tight tracking `-0.015em`; the type *is* the hero visual |
| H1 | 36 / 1.1 | 700 · wdth 112 | |
| H2 | 28 / 1.15 | 700 · wdth 108 | |
| H3 | 22 / 1.25 | 650 · wdth 100 | |
| Body L | 18 / 1.55 | 400 | Chat bubbles, plan steps (older users) |
| Body | 16 / 1.55 | 400 | Default; **never below 16px for body** |
| Small | 14 / 1.45 | 450 | Timestamps, hints |
| Score numeral | 72–96 / 1 | 800 · `font-variant-numeric: tabular-nums` | |

- Devanagari body: line-height **1.7**, no negative letter-spacing, no width-axis stretching.
- Line length ≤ 68 characters on reading surfaces.
- **Do not** use ALL CAPS for labels, tracked eyebrows, or "WORD — fragment" labels. Use sentence case.
- Do not accent a single word in a headline.

## 4. Shape, spacing, layout

- Spacing scale: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 72.
- **Radii by role (intentionally varied):** inputs/buttons `10px`; cards/panels `14px`; chat bubbles `20px` with a `6px` corner on the speaker's tail side; sheets `28px` top corners; chips and belts `999px`; phone frame `36px`.
- Max content width: 1120px; reading column 680px. Mobile gutters 16px.
- Mobile-first. Bottom tab bar (3 modes + dashboard). Desktop ≥ 1024px: left rail + centre stage + optional right context panel.
- Left-align text. Centre only the hero score and empty states.
- Tap targets ≥ 48×48px. Primary actions in the thumb zone (bottom).
- Subtle **tatami grid** (2:1 rectangle outlines at 4% opacity, SVG background) behind the hero and the dashboard header only.

### Iconography
`lucide-react`, 1.75px stroke, 20/24px. Custom SVG only for: **belt**, **strike** (a short diagonal slash mark used as the "landed" glyph), **block** (a bracket/shield outline used as the "blocked" glyph), logo.

### Logo
Wordmark "Scam Dojo" in Anek 800 wdth 118, with a small knot mark (belt knot built from two crossed rounded rectangles) left of it. Favicon = the knot on `--action`.

### Imagery
No stock photos. Geometric SVG illustration only, derived from tokens.

## 5. Motion

Principles: **motion answers an action or reveals an outcome.** No entrance animations on every section; no hover-lift on every card.

| Moment | Spec |
|---|---|
| **Hero SMS** (orchestrated moment #1) | On load, the SMS bubble types in over 900ms; three choice buttons appear after 400ms. The chosen outcome slides a response panel up (260ms, `cubic-bezier(.2,.8,.2,1)`). |
| Chat | Typing indicator (3 dots, 1.2s loop) while the Scammer streams its first token; tokens append without layout shift. |
| Pressure meter | Eases (400ms) to new value; colour steps matcha → kihada → beni. |
| Strike markers in debrief | Replay animates top→bottom once on first view, 120ms stagger, each marker "stamps" (scale 1.15→1, 140ms). Skip on revisit. |
| **Belt tightening** (orchestrated moment #2) | Belt draws in (stroke-dashoffset 600ms), knot pulses once, colour cross-fades if the belt changed, score counts up (900ms). Optional haptic `navigator.vibrate(30)` on belt change. |
| Checklist (Recover) | Tick draws in 160ms; completed step collapses to one line. |
| Sheets / dialogs | 220ms slide + fade. |

`prefers-reduced-motion: reduce` → replace all with 120ms opacity fades; no counting, no stamping, no pulsing. This is mandatory.

- **Check** — "Not sure about a message? We'll look."
- **Recover** — "Already paid or shared something? Start here."

### 6.7 Recover: intake (wizard, 5 short steps, one question per screen)
1. What happened? (UPI payment, card details shared, OTP shared, remote-access app installed, clicked link, bought something, investment/job, other)
2. When? (Just now / Within 1 hour / Today / 1–3 days / Longer)
3. How much and how? (amount ₹ range chips + payment method)
4. Which bank / app? (searchable list; "Not sure")
5. Anything else you'd like us to know? (optional free text)
Header copy: "You're not alone, and acting quickly helps. This takes under a minute." No guilt language anywhere.

### 6.8 Recover: plan

└────────────────────────────────────────────────┘

Checklist state persists (Firestore). Copy buttons confirm with a toast "Copied".

### 6.9 Trace panel (judge/dev view, `?trace=1` or toggle in `/demo`)
A right-hand panel (bottom sheet on mobile) that streams agent events:
```
Turn 4
 observer_agent · flash-lite · 612ms
   user_action: complied · leaked: [otp] · suspicion 3/10 → escalate (fear)
 scammer_agent · flash · first token 1.1s
   stage: extraction · tactic: fear
```
Collapsible JSON for each. Styled as a calm inspector, not a terminal cosplay.

### 6.10 Dashboard
Header: belt + score numeral + streak (flame-less: use a knot-count "5 days"). Then: **trend line** (last 20 sessions, tooltip), **tactic weakness radar** (6 axes: urgency, authority, fear, greed, trust, isolation), **next drill** card ("You're most pulled by authority. Try 'Digital arrest'."), **history list** (Train / Check / Recover events, filterable).

## 8. Accessibility (non-negotiable)

- WCAG 2.2 AA. Visible focus ring: 3px `--action` outline + 2px offset on all interactive elements.
- Chat transcript is an `aria-live="polite"` log; streaming announces on message end, not per token.
- Verdicts and strike/block never colour-only (icon + text).
- Support text scaling to 200% without clipping; layout uses `rem`.
- Full keyboard path for every flow; `Esc` closes sheets; focus trapped in dialogs.
- Language attribute switches (`lang="hi"`) on `<html>`; Devanagari font loads on demand.
- Error messages are specific and actionable, announced via `role="alert"`.
- Contrast CI check; Lighthouse a11y ≥ 95.

## 9. Voice and microcopy

Rules: sentence case, plain verbs, active voice, one job per element; an action keeps one name through the flow ("Check it" → toast "Checked"). Errors explain what happened and what to do, without apologising or vague "Oops".

## 10. Belt system (visual + rules mirror)

White 0–19 · Yellow 20–34 · Orange 35–49 · Green 50–64 · Blue 65–76 · Brown 77–89 · Black 90–100 (black also requires ≥ 3 different scenarios completed at difficulty ≥ 3). Rank names displayed as "Green belt" / "हरी बेल्ट". Logic lives in the backend (`4.agents.md` §3.4); the UI only renders what the API returns.

## 11. Share card ("Warning card")

Client-rendered 1080×1350 image (html-to-image): top: verdict + scam type in plain language; middle: 3 red flags; bottom: "Checked with Scam Dojo" + URL. **No user text or PII is included by default** (only the scam type and generic flags). Share via Web Share API with a download fallback. Designed for WhatsApp family groups.
