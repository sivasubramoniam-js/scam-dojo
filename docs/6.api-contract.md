# 6. API Contract (v1)

Source of truth for request/response shapes. FastAPI must emit an OpenAPI document matching this; the frontend generates types from it (`make openapi`). All bodies are JSON unless noted. Field names are `camelCase` on the wire (configure Pydantic `alias_generator=to_camel`, `populate_by_name=True`).

**Base URL:** `${NEXT_PUBLIC_API_URL}` · **Auth:** `Authorization: Bearer <Firebase ID token>` on every `/v1/*` (dev: `X-Dev-User`). **Language:** `Accept-Language: en|hi` (or `?lang=`). **Trace:** `?trace=1` adds `trace` SSE events. **IDs:** opaque strings.

---

## 1. Conventions

### Error envelope (all non-2xx)
```json
{ "error": { "code": "rate_limited", "message": "Daily limit reached", "messageKey": "error.rate", "retryable": false, "retryAfterSec": 3600, "requestId": "req_ab12" } }
```
| HTTP | `code` | Notes |
|---|---|---|
| 400 | `bad_request` / `invalid_file` / `file_too_large` / `unsupported_media` | `messageKey`: `error.invalid_file` etc. |
| 401 | `unauthenticated` | missing/expired token |
| 403 | `forbidden` | |
| 404 | `not_found` | also used when a resource belongs to another user |
| 409 | `session_not_active` / `duplicate_message` | |
| 422 | `validation_error` | with `details[]` |
| 429 | `rate_limited` | `retryAfterSec` |
| 502/503 | `model_busy` / `model_error` | `retryable: true` |
| 500 | `internal` | no stack traces |

### SSE format
`Content-Type: text/event-stream`. Events: `event: <name>\ndata: <json>\n\n`. Heartbeat comment `: ping` every 15s. Always ends with `event: done` `data: {}`. If an error occurs mid-stream: `event: error` with the error envelope body, then `done`. Every streaming endpoint accepts `?stream=false` → single JSON response containing the final payload.

### Common types
```ts
type Lang = 'en' | 'hi';
type Belt = 'white'|'yellow'|'orange'|'green'|'blue'|'brown'|'black';
type Tactic = 'urgency'|'authority'|'fear'|'greed'|'trust'|'isolation';
type Channel = 'sms'|'chat'|'phone_sms'|'email'|'call';
type TraceEvent = { runId: string; turn?: number; agent: string; model?: string; kind: 'start'|'output'|'code'|'end'|'error';
                    latencyMs?: number; summary: string; payload?: unknown };
```

## 3. Me

### `GET /v1/me` → `Me` (creates the profile on first call)
```ts
type Me = { uid: string; displayName?: string; isAnonymous: boolean; language: Lang; timezone: string;
```

### `PATCH /v1/me` body `{ language?, displayName?, timezone?, settings? }` → `Me`
### `DELETE /v1/me/data` → `204` (deletes all user data; optional `?deleteAccount=true`)
### `GET /v1/me/export` → `application/json` (all user documents)

## 5. Train

### `POST /v1/train/sessions`
Body: `{ scenarioSlug: string; difficulty?: 1|2|3|4|5 | "auto"; lang?: Lang; demo?: boolean }`
→ `201`
```ts
{ sessionId: string; scenario: { slug: string; title: string; channel: Channel; personaName: string; orgLabel: string /* e.g. "Orion Bank (simulated)" */ };
  difficulty: number; maxUserTurns: number /*14*/; tension: number /*0..10*/; stage: 'hook';
  messages: ChatMessage[] /* contains opening scammer message */ ; startedAt: string }
type ChatMessage = { i: number; role: 'scammer'|'user'|'sensei'; text: string; ts: string; piiRemoved?: string[] };
```
Errors: `404` unknown scenario · `403` locked belt · `429`.

### `POST /v1/train/sessions/{sid}/messages` (SSE)
Body: `{ text: string /*≤500*/; clientMsgId: string /*uuid, idempotency*/ }`
Events:
| event | data |
|---|---|
| `ack` | `{ i: number; text: string /*scrubbed*/; piiRemoved: string[] }` |
| `state` | `{ turn: number; tension: number; stage: string; status: 'active'|'ending' }` (sent after Observer, before tokens) |
| `token` | `{ delta: string }` |
| `message_end` | `{ i: number; text: string; role: 'scammer'|'sensei' }` |
| `session_end` | `{ outcome: 'user_won'|'user_fell'|'max_turns'; reason: string }` (then client navigates to debrief) |
| `trace` | `TraceEvent` (only with `?trace=1`) |
| `error` / `done` | see conventions |
Re-sending the same `clientMsgId` returns the stored result (as a replay) with no model calls.
`?stream=false` → `{ ack, state, message: ChatMessage, sessionEnd? }`.

### `POST /v1/train/sessions/{sid}/end` → `200` (idempotent; non-stream)
Body: `{ reason?: 'walked_away'|'timeout' }` (ignored if already ended). Runs scoring + Coach (≤ 30s).
```ts
{ sessionId: string; outcome: 'user_won'|'user_fell'|'walked_away'|'max_turns';
  score: { final: number; outcomePoints: number; flagPoints: number; verifyPoints: number; dataPoints: number; coachAdj: number };
  resilience: { before: number; after: number }; belt: { before: Belt; after: Belt; changed: boolean; progress: number };
  debrief: Debrief; degraded: boolean;
  nextDrill: { slug: string; reason: string }; streak: { current: number; best: number } }
```
`Debrief` as defined in `4.agents.md` §3.5 (camelCase on the wire; `moments[].turnIndex` etc.).

### `GET /v1/train/sessions/{sid}` → 
`{ sessionId, scenario: {...}, status: 'active'|'ended', difficulty, tension, stage, turnCount, messages: ChatMessage[], outcome?, end?: <same as /end response> }`

### `GET /v1/train/sessions?limit=20&cursor=` → `{ items: TrainSummary[], nextCursor?: string }`
`TrainSummary = { sessionId, scenarioTitle, startedAt, outcome, finalScore, belt, difficulty }`

## 6. Check

### `POST /v1/check` — `multipart/form-data` → SSE
Fields: `text?: string (≤5000)`, `files?: File[] (≤3)`, `lang?`, `fromHeroSample?: boolean`. At least one of `text`/`files` is required.
Events:
| event | data |
|---|---|
| `stage` | `{ id: 'extracting'|'matching'|'analysing'; label: string }` |
| `indicators` | `{ urls: n; phones: n; upiIds: n; keywordTags: string[]; shortener: boolean; webRisk?: 'safe'|'unsafe'|'unknown' }` |
| `result` | `CheckResult` |
| `trace` | `TraceEvent` |
| `error` / `done` | |
```ts
type CheckResult = { checkId: string; createdAt: string; verdict: 'likely_scam'|'suspicious'|'likely_safe'|'cannot_tell';
  riskScore: number; scamType?: string; scamTypeLabel?: string; oneLine: string; explanation: string;
  redFlags: { id: number; quote: string; why: string; severity: 'low'|'medium'|'high'; source: 'text'|'image'|'video'|'audio'|'indicator' }[];
  reassuringSignals: string[]; doNow: string[]; dontDo: string[]; verifyHow?: string; needsMoreInfo: string[];
  alreadyActedHint: boolean; confidence: 'low'|'medium'|'high'; languageDetected: string;
  inputTypes: ('text'|'image'|'video'|'audio')[]; degraded?: boolean;
  resources?: Resource[] /* present when alreadyActedHint */ }
```
### `GET /v1/check/{cid}` → `CheckResult` (+ `textPreview?: string`)
### `GET /v1/checks?limit=10` → `{ items: { checkId, createdAt, verdict, riskScore, oneLine, inputTypes }[] }`
### `POST /v1/check/{cid}/to-drill` → `201` `{ scenarioSlug: "custom:<id>", title: string }` (Forge; `409` if verdict is `likely_safe`)

## 7. Recover

### `POST /v1/recover/plans` (SSE)
Body:
```ts
{ incident: ('upi_payment'|'card_details_shared'|'otp_shared'|'bank_transfer'|'remote_app_installed'|'link_clicked'|'aadhaar_pan_shared'|'purchase_scam'|'investment_or_job'|'threatened'|'other')[];
  timeSince: 'just_now'|'within_1h'|'today'|'1_3_days'|'longer';
  moneyLost: boolean; amountBand?: 'lt_1k'|'1k_10k'|'10k_50k'|'50k_2l'|'gt_2l'|'unknown';
  paymentMethod?: 'upi'|'card'|'net_banking'|'wallet'|'cash'|'crypto'|'other';
  bank?: string; notes?: string /*≤1000, scrubbed*/; fromCheckId?: string; lang?: Lang }
```
Events: `stage` (`reading` | `selecting_resources` | `planning`), `resources` (`{ items: Resource[] }` — send early so the UI can show critical contacts immediately), `result` (`PlanResult`), `trace`, `error`, `done`.
```ts
type PlanResult = { planId: string; createdAt: string; urgency: 'critical'|'high'|'moderate'|'low'; summary: string;
  steps: { id: string; phase: 'now'|'today'|'this_week'|'protect_next'; title: string; why: string; how: string[];
           resources: Resource[]; draftText?: string; draftLabel?: string; timeCritical: boolean; done: boolean }[];
  whatToExpect: string[]; evidenceChecklist: string[]; protectNext: string[]; suggestedDrill?: { slug: string; title: string };
  degraded: boolean; disclaimer: string; resourcesVerifiedOn: string }
```
### `GET /v1/recover/plans/{pid}` → `PlanResult` + `chat: { role, text, ts }[]` + `intake`
### `GET /v1/recover/plans?limit=` → `{ items: { planId, createdAt, urgency, progress: { done: n, total: n } }[] }`
### `PATCH /v1/recover/plans/{pid}/steps/{stepId}` body `{ done: boolean }` → `{ stepId, done, progress: { done, total } }`
### `POST /v1/recover/plans/{pid}/chat` (SSE) body `{ text: string }`
Events: `token {delta}`, `message_end {text}`, `trace`, `error`, `done`. Non-stream: `{ message: { role:'assistant', text } }`.

## 9. Non-functional contract
- **Latency targets (server, excluding network):** `POST /v1/train/sessions` < 400ms · first `token` < 2.0s p50 · full Scammer message < 6s · `/end` < 15s p50 · `/check` `result` < 12s p50 (image) · plan `result` < 20s p50.
- **Idempotency:** `clientMsgId` for Train messages; `POST /v1/train/sessions/{sid}/end` idempotent.
- **Size limits:** JSON ≤ 64KB; multipart ≤ 25MB total.
- **CORS:** allow-listed origins; allow headers `Authorization, Content-Type, Accept-Language, X-Request-ID, X-TZ`; expose `X-Request-ID`.
- **Versioning:** path-prefixed `/v1`; additive changes only during the event; OpenAPI snapshot test guards the contract.
- **Caching:** all `/v1` responses `Cache-Control: no-store` except `/v1/stats/global` (60s) and `/v1/scenarios` (`private, max-age=300`).
